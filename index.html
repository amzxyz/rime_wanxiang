    🚀 快速上手 ⭐ GitHub 仓库

    🧭 探索万象¶

    • 快速上手

      从零开始，为您在 Windows、macOS 以及 iOS/Android 移动端部署万象。

      立即安装

    • 核心输入体系

      深入解析万象独特的“带调拼音标注”、强大的辅码系统（小鹤、自然码等）以及中英混输机制。

      了解核心

    • Lua 魔法扩展

      计算器、超级注释、符号包裹、动态时间戳... 探索让 Rime 拥有“超能力”的数十种微创新脚本。

      探索魔法

    • 词库与模型

      深度解析万象的现代数据工程。算一笔隐形的“时间账”，彻底告别低效的候选翻页，让输入如呼吸般自然。

    💎 选择适合你的万象¶

    四个版本共享万象的核心数据体系，但在 功能完整度、辅助码、Lua 扩展与运行环境 上各有侧重。

    🟢

    Base

    完整、通用、开箱即用

    大多数用户首选
    适合谁全拼、普通双拼、第一次使用万象的用户
    输入体系全拼 + 任意双拼
    词库完整带调万象词库
    Lua 能力完整：预测、计算器、时间、符号、提示、造词等
    不知道选什么 → Base
    🔵

    Pro

    双拼与辅助码深度增强

    高阶用户
    适合谁双拼重度用户、辅助码用户
    输入体系双拼 + 多套辅助码
    词库独立 Pro 辅助码词库
    核心特点精准筛选、固定编码、造词与更强控制
    双拼 + 辅助码 → Pro
    🍃

    Lite

    轻量，但保留现代体验

    轻量首选
    适合谁不需要复杂预测、造词与高级模块的日常用户
    输入体系全拼 + 双拼
    词库无声调 Lite 词库
    Lua 能力保留常用功能，裁掉部分重模块
    想轻一点 → Lite
    ❄️

    Pure

    原生核心，兼容性优先

    特殊环境
    适合谁老系统、旧 Rime、Lua 不可用环境
    运行核心Rime 原生 Processor / Translator / Filter
    Lua 能力不携带 Lua
    典型环境Win7、fcitx4-rime 等
    兼容性第一 → Pure
