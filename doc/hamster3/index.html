    Hamster3 (元书输入法) 部署指南¶

    欢迎在 iOS 平台使用万象。Hamster3（元书输入法）支持多套 Rime 方案共存，并提供独立的方案目录、文件同步和部署管理机制。

    1. 启用键盘与完全访问权限¶

    1. 安装元书输入法后，前往系统 设置 → 通用 → 键盘 → 键盘 → 添加新键盘，添加 Hamster。
    2. 点击 Hamster 键盘项，开启 【允许完全访问】。
      • 未开启完全访问时，万象 Pro 版的部分双拼切换和 Lua 功能可能无法正常运行。

    2. 建立独立的万象目录¶

    元书支持多套方案共存。为了便于后续管理，建议为万象单独建立一个方案目录。

    1. 打开 iOS 自带的 文件 App。
    2. 进入路径：我的 iPhone/元书输入法/RimeUserData。
    3. 在该目录中新建文件夹，建议命名为：wanxiang。

    3. 导入万象方案¶

    打开元书输入法 APP，进入 【输入方案】 页面：

    • 方式 A：通过下载链接导入

    点击右上角菜单，选择 【下载方案】，填入万象 Release 中对应方案 .zip 文件的下载链接。

    • 方式 B：手动导入

    提前下载对应的 .zip 方案包，然后选择 【导入方案】 并选取该文件。

    导入完成后，再次点击右上角菜单，选择 【方案目录切换】，切换到前面创建的 wanxiang 目录。

    4. 执行部署与基础配置¶

    1. 在【输入方案】页面，点击菜单旁的 【刷新】 按钮，执行首次部署。
    2. 皮肤和按键处理方式可参考仓输入法相关设置，重点确认斜杠 / 等需要参与 Rime 编码的按键由 Rime 处理，而不是由前端直接上屏。

    5. 键盘文件与应用文件的同步机制¶

    元书输入法在部署前会自动将部分键盘文件同步回应用目录。默认同步范围主要包括 text 和 userdb 等数据，并不会自动包含 .yaml 配置文件。

    如果希望通过斜杠指令修改配置，并在后续部署后继续保留这些修改，可以根据自己的使用方式选择下面两种方案：

    适合人群：主要通过键盘斜杠指令切换输入类型，希望相关 custom 配置在部署前自动同步回应用目录的用户。

    1. 进入 我的 iPhone/元书输入法/RimeSharedSupport。
    2. 将 include_keyboard_rime_files.txt 复制到自己的 wanxiang 目录。
    3. 编辑该文件，在末尾新增一行：
    ^.*[.]custom.*$
    1. 保存后，键盘端产生的 custom 配置文件即可纳入同步范围，在后续部署前同步回应用文件。

    注意应用文件被键盘文件覆盖

    开启这种同步方式后，匹配到的 custom 文件会以键盘文件为同步来源。

    如果平时还会在电脑或其他编辑器中修改 RimeUserData/wanxiang 中的 custom 文件，需要注意部署前的同步方向，避免应用目录中的新修改被键盘端旧文件覆盖。

    适合人群：习惯直接编辑配置文件，希望所有 custom 修改都由自己手动管理，不希望键盘端记录自动覆盖应用文件的用户。

    • 操作方式：无需修改 include_keyboard_rime_files.txt，保持默认同步范围即可。

    • 斜杠指令限制：键盘端通过斜杠指令产生的 custom 修改不会自动同步回应用文件，因此重新部署后可能无法继续保留。

    • 配置方式：需要修改 custom 文件时，直接通过 iOS 文件管理或其他文本编辑器编辑 RimeUserData/wanxiang 目录中的对应文件。

    • 示例文件：方案中 custom 目录下的文件用于提供配置示例。需要实际使用时，应将对应文件复制到 RimeUserData/wanxiang 目录后再进行修改。

    6. 初始指令与输入类型切换¶

    如果选择了路线 A，可以直接通过键盘斜杠指令切换；路线 B 用户则应手动修改对应配置文件。

    万象默认使用以下输入方式：

    • Base 标准版：默认开启 全拼。
    • Pro 增强版：默认开启 自然码双拼。

    建议执行一次方案切换指令

    即使当前默认输入方式已经符合使用习惯，也建议主动执行一次对应的斜杠指令，使相关方案中的输入类型配置保持一致。

    操作方法：在键盘的中文输入状态下输入对应指令，完成切换后返回元书输入法 APP，点击 【刷新】 重新部署。

    需要注意一些手机前端涉及到皮肤的自定义，需保证斜杠是rime处理的而不是直接上屏的，用什么软件就去哪里学习
